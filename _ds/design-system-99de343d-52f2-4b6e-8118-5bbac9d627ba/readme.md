# ИнтеллектКАЗС — Design System

Дизайн-система компании **ИнтеллектКАЗС** (Санкт-Петербург) — производителя контейнерных автоматических заправочных станций (КАЗС), резервуаров (РГС/РВС), ТРК и систем автоматизации АЗС. Полный EPC-цикл: проектирование → производство → монтаж → сервис 24/7.

Система собрана из живого сайта-источника: проект `f9d4fbfa-ae65-4daf-b7ba-fcd486573a82` (страницы `index.html` — ведомственная КАЗС, `kommercheskaya.html` — коммерческая КАЗС, `home.html` и ~40 внутренних страниц; общий `styles.css`). Ссылка пользователя: https://claude.ai/design/p/f9d4fbfa-ae65-4daf-b7ba-fcd486573a82?file=kommercheskaya.html

**Кредо визуального стиля: «Белый зал с одним синим выключателем»** — Apple-frost эстетика: почти монохромный светлый интерфейс, синий существует в трёх строго разделённых ролях, продукт (станция) — главный герой каждой страницы.

## Продукты / поверхности
- **Маркетинговый сайт** (основная поверхность): лендинги продуктов, страницы моделей, калькуляторы, FAQ, кейсы.
- **Документы**: коммерческие предложения (КП) и деловые письма на базе той же типографики и токенов.
- **Презентации**: слайды 16:9 на брендовых шаблонах.

## CONTENT FUNDAMENTALS (тон и копирайтинг)
- Язык — русский, обращение на **«вы»** (строчная), прямое и деловое: «Сократите топливные затраты автопарка на 15–25% за 8 месяцев».
- Заголовки — выгода с конкретной цифрой; цифры всегда точные: «45 дней», «−50…+40 °C», «маржа 4–8 ₽ с литра», «окупаемость ~7 мес.».
- Короткие рубленые фразы, иногда парцелляция: «Без операторов. Без сбоев. Без перерывов.»
- Апплевский приём в заголовках: акцентное слово внутри фразы красится в signal-blue (`.accent`): «Продукт **и есть** дизайн.»
- Айброу (`.t-eyebrow`) — короткая тематическая метка КАПСОМ над заголовком: «Флагман», «Калькулятор окупаемости».
- CTA — глагол в императиве: «Рассчитайте свою экономию», «Заказать звонок», «Получить бизнес-план и КП».
- Честный, инженерный тон; допускается разговорная прямота: «Напишите честно — учтём это в коммерческом предложении».
- Кавычки — «ёлочки»; тире — длинное; неразрывные пробелы перед короткими словами; **эмодзи не используются**.
- Числа и единицы — моноширинным (`.mono`, JetBrains Mono, tnum).

## VISUAL FOUNDATIONS
### Цвет — «один цвет, одна работа»
- `--apple-blue #0071e3` — ТОЛЬКО заливка primary-кнопок и выбранных состояний.
- `--link-blue #0066cc` — outline-кнопки и текстовые ссылки.
- `--signal-blue #2997ff` — только декор: акцентные слова, рамки, точки на карте, прогресс таймлайна.
- Нейтрали: `--carbon #1d1d1f` (текст/тёмные карточки), `--frost #f5f5f7` (фон страницы), `--ice #f4f8fb` (чередующиеся секции), `--ash #707070` / `--mist #858585` (вторичный текст), `--onyx #000` (тёмные секции), `--hairline #d2d2d7` (все бордеры).
- `--success #30d158` — только позитивные метрики (экономия, ROI).
- Фоновый ритм секций: frost → ice → frost → dark (onyx/carbon) → banner-фото → frost.

### Типографика
- Текст: **Inter** (300/400/500/600, максимум 600 — жирнее не бывает). Отрицательный letter-spacing на крупных кеглях.
- Цифры/код: **JetBrains Mono** + `font-feature-settings: "tnum"`.
- Шкала — классы: `.t-hero` (46–92px), `.t-display` (40–56), `.t-heading-lg` (34–44), `.t-heading` (30–40), `.t-heading-sm` (22–28), `.t-sub` (19–21, weight 300, цвет ash), `.t-eyebrow` (12px caps).
- Body: 17px / 1.47 / −0.272px.

### Форма и поверхность
- Радиусы: карточки/поля **8px**; кнопки — полные пилюли **980px**; модалки 20–22px.
- Карточки: белый фон + 1px `--hairline`, БЕЗ тени; hover — `translateY(-4px)` + бордер темнеет. Тени только у плавающих слоёв (модалки, чат, дропдауны).
- Продуктовые рендеры: белый фон рендера гасится `mix-blend-mode: multiply` (`.blend`), «приземление» — `drop-shadow` (`.grounded`); подложка — градиент `#fff → #f0f0f3`.
- Тёмные секции (`.dark`, `.dark-2`) для контроля/географии; полноэкранные фото-баннеры (`.banner`) с защитным градиентом слева или снизу.
- Стекло: фикс-навигация `rgba(0,0,0,.55)` + `backdrop-filter: blur(18px) saturate(160%)`; дропдауны — белое стекло 0.93.
- Анимации: единый изинг `cubic-bezier(0.25,0.1,0.25,1)` (`--ease`), scroll-reveal (fade+26px up, каскад задержек .08s), flip-карточки 3D, пульсирующие точки географии. Никаких bounce.
- Hover: кнопки — чуть светлее + `translateY(-1px)`; ghost-ссылка `›` сдвигается вправо; изображения в карточках `scale(1.05)`.
- Единственное «радужное» исключение: AI-консультант и бэкдроп модалки звонка — анимированный градиент (`ai-shift`).

### Layout
- Контейнер `--page-max: 1440px`, паддинг 40px (22px мобайл); текстовая колонка `--text-col: 980px`.
- Секции: `clamp(72px,10vw,130px)` вертикали; сетки 3-колоночные (2 на планшете, 1 на мобиле); bento-грид на home.
- Счётчики и spec-row разделяются вертикальными hairline, не карточками.

## ICONOGRAPHY
- Иконки — **инлайновые SVG, stroke 1.3–1.4, без заливки, `currentColor`**, viewBox 24, скругления минимальные. Стиль близок к Lucide/Feather с тонким штрихом — при нехватке рисуйте в этом же стиле или берите Lucide со stroke-width 1.4.
- Размер 30–32px, цвет carbon (на тёмном — frost).
- Юникод-символы как микро-иконки: `›` (ghost-стрелка), `▾` (caret), `«»` (возражения), `+` (FAQ, рисуется CSS).
- Эмодзи не используются. Иконочных шрифтов нет.
- Логотип: `assets/logo-mark.png` (синий куб-марка 30×30) + словесный знак текстом: `Интеллект<b>КАЗС</b>` (300 + 600).

## Компоненты (React-примитивы, `components/`)
Пространство имён рантайма — `window.DesignSystem_99de34`.

- **core/** — `Pill`, `Eyebrow`, `GhostLink`, `SectionHead`
- **forms/** — `Field`, `TextArea`
- **data/** — `Counter`, `Spec`, `FaqItem`, `Timeline`
- **cards/** — `AdvCard`, `ModelCard`, `CaseCard`, `FlipCard`, `ObjCard`, `LinkCard`
- **sections/** — `Nav`, `Banner`, `Footer`

Каждый компонент: `<Name>.jsx` + `<Name>.d.ts` + `<Name>.prompt.md`, в каждой папке — карточка-витрина `*.card.html`. Стилизация — через CSS-классы боевого `styles.css` (не CSS-in-JS).

## Шаблоны (`templates/`)
Стартовые Design Components для потребляющих проектов:
- **kp/** — `Коммерческое предложение` (A4): шапка с реквизитами, спецификация, итог, условия, подпись.
- **letter/** — `Деловое письмо` (A4) на бланке: адресат, тело, подпись.
- **slides/** — `Слайды 16:9`: титул (фото), ключевая метрика, продукт-шоукейс, цитата.

## Индекс файлов
- `styles.css` — точка входа (@import токенов + база + компоненты).
- `tokens/colors.css` · `tokens/typography.css` · `tokens/layout.css` — палитра, шрифты/шкала, отступы/радиусы/тени/motion.
- `css/base.css` — reset, тип-шкала, layout-утилиты, кнопки. `css/components.css` — все секции сайта (nav, hero, cards, calc, faq, footer, geo, chat, call-modal…).
- `assets/` — логотип-марка, продуктовые рендеры (flagship, tank-white, product-white, model-iso, terminal…), фото-баннеры (hero-night, comm-lenta, night-2, city-morning…), кейсы, производство.
- `guidelines/` — specimen-карточки (Colors / Type / Spacing / Brand) для вкладки Design System.
- `components/` — React-примитивы (см. выше).
- `ui_kits/website/` — интерактивная рекреация лендинга (hero → доверие → флагман → модели → баннер → FAQ → CTA → футер → модалка).
- `templates/` — КП, письмо, слайды.
- `SKILL.md` — навык для Claude Code / Agent Skills.

## Intentional additions
- **templates/** (КП, письмо, слайды) — в источнике деков/документов не было; собраны строго из токенов и типографики сайта по явному запросу пользователя («документы, КП, письма»).
- **Компоненты `Timeline`, `FlipCard`** — соответствуют секциям процесса и аудитории на сайте-источнике; вынесены в переиспользуемые примитивы.

## Известные пробелы
- Полноцветного логотипа/лого-гайда нет — только марка `logo-mark.png` + текстовый словесный знак. Логотип НЕ реконструировался.
- Шрифты (Inter, JetBrains Mono) грузятся с Google Fonts — офлайн-файлов `.ttf`/`.woff` в источнике нет, поэтому `@font-face` в системе отсутствует. При необходимости офлайн-сборки пришлите файлы шрифтов.
- `cinematic.css/js` (скролл-видео интро) и видео `cine/*.mp4` — специфика одной страницы, в систему не включены; брать из проекта-источника.
