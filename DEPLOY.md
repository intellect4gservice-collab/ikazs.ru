# Деплой ikazs.ru на Джино

## Что грузится на сервер

Всё из корня репозитория, **кроме**: `uploads/`, `scraps/`, `screenshots/`, `_ds/`, `.github/`, `.git/`, `*.md`, `*.docx`, `*.xlsx`, `_probe.html`, `Бриф*.html`.

Это ровно то, что нужно сайту: 54 страницы `*.html`, `styles.css`, `mobile.css`, `cinematic.css`, `pages-info.css`, `app.js`, `mobile.js`, `support.js`, `cinematic.js`, `kazs-viewer.jsx`, `assets/**`, `.htaccess`, `robots.txt`, `sitemap.xml`.

**Почему не всё:** `uploads/` содержит внутренние документы (ТЗ, контент-док, SEO-дамп, оригиналы видео), `scraps/` — старые версии страниц. На сервере они были бы доступны по прямой ссылке любому и попали бы в индекс поисковиков.

## Тариф

Хостинг «Начальный», производительность **X1 (129 ₽/мес)**. Сайт статический — PHP и MySQL **не нужны**, отключить. Диск 20 ГБ. Итого ≈130–230 ₽/мес.

## Первичная настройка на Джино

1. Создать контейнер хостинга (X1, без PHP, без MySQL).
2. Домены → привязать `ikazs.ru` и `www.ikazs.ru` к контейнеру.
3. Включить бесплатный SSL (Let's Encrypt) для обоих. **Дождаться выпуска сертификата** — только потом заливать `.htaccess`, иначе редирект на https уйдёт в цикл.
4. Залить файлы в корень сайта (FTP/FTPS или git-деплой).
5. Проверить: `https://ikazs.ru` открывается, `http://` и `www` редиректят на него.

## Автодеплой из GitHub

Workflow: `.github/workflows/deploy.yml` (FTPS). В настройках репозитория → Settings → Secrets and variables → Actions добавить:

| Секрет | Значение |
| --- | --- |
| `FTP_SERVER` | хост FTP из панели Джино |
| `FTP_USERNAME` | логин FTP |
| `FTP_PASSWORD` | пароль FTP |
| `FTP_DIR` | путь к корню сайта, например `/domains/ikazs.ru/public_html/` |

Дальше любой `push` в `main` обновляет сайт.

⚠️ Убедиться, что `.htaccess` реально загрузился — некоторые FTP-клиенты скрывают файлы, начинающиеся с точки.

## Что делает .htaccess

- 301-редирект на `https://ikazs.ru` (без `www`) — один канонический адрес для Яндекса
- gzip для html/css/js
- кэш: медиа на год `immutable`, css/js на неделю, html без кэша
- `Accept-Ranges` для mp4/webm — чтобы видео можно было перематывать и подгружать частями
- 404 на `/uploads/`, `/scraps/`, `/screenshots/`, `/_ds/` — страховка, если что-то залилось вручную
- `Options -Indexes` — запрет листинга папок
- 404-страница → `soon.html`

## После запуска

1. Яндекс.Вебмастер: добавить сайт, подтвердить права, указать главное зеркало `ikazs.ru`, регион, загрузить `sitemap.xml`.
2. Яндекс.Метрика: поставить счётчик (пока не установлен ни на одной странице).
3. Проверить скорость на мобильном — если видео тормозят, вынести `assets/*.mp4|webm` в Хранилище S3 Джино.

## Известные нюансы

- `configurator.html` тянет React, three.js и Babel с `unpkg.com` — это dev-сборки, страница будет грузиться заметно медленнее остальных. При необходимости положить библиотеки локально в `assets/vendor/` и переключить на production-сборки.
- Личный кабинет клиента на этом хостинге не поднять. Стенд — на существующем VPS (в т.ч. Hetzner), прод — только российский сервер: персональные данные заказчиков по 152-ФЗ должны храниться в РФ.
